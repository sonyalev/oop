## 🔹 Лабораторна 3 - DI-фреймворк (аналог PicoContainer)

Мінімалістичний **фреймворк впровадження залежностей**

**Особливості:**
- Анотації `@Inject` та `@Singleton`;
- Автоматичне створення об’єктів із залежностями;
- Обробка циклічних залежностей;
- Простий API для реєстрації класів та інтерфейсів;
- Тестове покриття основних сценаріїв DI.
